# Cadence

Cadence manages audio on USB storage on Android, desktop, and in your browser.

- [Open the browser app](app/)
- [Download Android and desktop releases](https://github.com/yschimke/cadence/releases/latest)
- [Setup and usage](https://github.com/yschimke/cadence#readme)
- [Privacy policy](privacy.html)

The browser app requires WebAssembly GC. Use desktop Chrome or Edge over HTTPS
for USB discovery and writable directory access. Select the device's mounted
folder to copy audio; WebUSB cannot claim its protected mass-storage interface.
